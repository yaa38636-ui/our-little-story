OUR LITTLE STORY — WEBSITE ANNIVERSARY

Cara membuka:
1. Ekstrak file ZIP ini.
2. Buka folder `anniversary_web` di Visual Studio Code.
3. Klik kanan `index.html` lalu pilih Open with Live Server (jika ekstensi Live Server tersedia).
   Alternatif: klik dua kali index.html untuk membukanya di browser.
4. Pastikan folder `assets` tetap berada di samping index.html, style.css, dan script.js.

Isi website:
- Amplop biru dapat diklik untuk membuka surat.
- Tombol lanjut membuka bagian Our Memories.
- Empat kartu foto dapat diklik untuk memperbesar gambar; gunakan panah atau keyboard kiri/kanan untuk pindah foto.
- Bagian akhir berisi penutup anniversary dan tombol untuk kembali ke awal.
- Layout responsif untuk HP dan laptop.

Catatan:
- Foto dan dekorasi menggunakan gambar yang kamu unggah.
- Font online memerlukan koneksi internet; jika offline, font cadangan tetap digunakan.
- Tanggal anniversary dan nama pasangan belum ditambahkan karena belum diberikan.

Lagu About You — The 1975:
- Setelah membuka amplop, masuk ke surat lalu tekan tombol "Putar lagu ♫".
- Pemutar memakai Spotify embed untuk menghindari error YouTube 153 yang muncul pada browser tertentu.
- Tekan tombol play pada pemutar Spotify. Durasi lagu sekitar 5 menit 26 detik; pemutaran penuh bergantung pada akun/dukungan Spotify dan koneksi internet.
- Musik disediakan oleh Spotify, bukan file audio yang disertakan di ZIP.

Catatan desain: foto asli yang kamu unggah dipakai tanpa mengubah wajah. Banner Our Memories bisa diklik untuk membuka galeri; ilustrasi burung dan bunga bergerak mengambang.
